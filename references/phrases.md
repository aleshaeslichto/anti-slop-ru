# Phrases to Remove (Russian)

The categories below collect recurring editorial patterns: officialese, formulaic openers, overblown claims, calques, and chatbot-style framing. Treat them as context-dependent clues, not as a list of words to ban mechanically.

## Throat-Clearing Openers (пустые подводки)

Remove these announcement phrases. State the content directly.

- «Стоит отметить, что…»
- «Важно отметить, что…»
- «Важно понимать, что…»
- «Важно помнить, что…»
- «Следует отметить, что…»
- «Следует подчеркнуть, что…»
- «Нельзя не отметить…»
- «Необходимо отметить, что…»
- «Можно с уверенностью сказать, что…»
- «Хочется отметить, что…»
- «Стоит подчеркнуть, что…»

Any «отметить/подчеркнуть/сказать» lead-in is announcing a point instead of making it. Cut the lead-in and keep the claim. The result is shorter and lands harder:

- «Стоит отметить, что сроки сократились» → «Сроки сократились».
- «Важно понимать, что данные уже в контуре» → «Данные уже в контуре».

## Era Clichés (штампы «современной эпохи»)

The most recognizable Russian AI opener: a claim about the times instead of the thing.

- «В современном мире…»
- «В современном мире, где технологии не стоят на месте…»
- «В эпоху цифровизации…»
- «В эпоху стремительного развития технологий…»
- «В условиях быстро меняющегося мира…»
- «В условиях высокой конкуренции…»
- «В условиях неопределённости…»
- «Технологии не стоят на месте»
- «Мир не стоит на месте»
- «Сегодня, как никогда…»

These announce that the next few hundred words are generic. Start with a fact, a number, or a concrete situation.

- «В современном мире данные становятся ключевым активом» → «Данные уже определяют сроки сдачи отчётов — вот пример с объекта N».

## Empty Superlatives (преувеличения без доказательств)

LLMs love scale. Each word is a marker if no fact nearby proves it.

- «революционный»
- «уникальный»
- «беспрецедентный»
- «непревзойдённый»
- «первоклассный»
- «инновационный»
- «прорывной»
- «передовой»
- «кардинально»
- «потрясающий»
- «новый уровень» / «новая эра» / «новая реальность»
- «неотъемлемая часть»
- «ключевой элемент»
- «максимально эффективный»
- «критически важный» / «стратегически важный»

Replace with the fact («снизили ошибки на 40%») or cut the adjective. «Революционный подход к управлению» without saying what is revolutionary is a shell; «срок с 14 дней до 3» needs no epithet.

## Business Jargon (маркетинговые клише)

Replace with plain language.

| Avoid | Use instead |
|-------|-------------|
| «Раскрыть потенциал» / «разблокировать потенциал» | «Использовать сильнее» / «получить X» |
| «Комплексный подход» / «комплексное решение» | List what is actually in it |
| «Открывает новые горизонты/перспективы/возможности» | Name the concrete new option |
| «Синергия» / «win-win» | «Совмещает X и Y» / «выгода для обеих сторон: …» |
| «Драйвер роста» / «двигатель роста» | «Что растит выручку» / «что ускоряет внедрение» |
| «Экосистема решений» / «ландшафт» / «парадигма» | «Набор модулей» / «рынок инструментов» / «подход» |
| «Лучшие практики» | Name the actual practice |
| «Exit-стратегия», «actionable insights», «value add» | Russian equivalent or the established term |

## Канцелярит (officialese) — the #1 Russian AI marker

LLMs turn verbs into abstract nouns and pad the sentence. This is the strongest tell in Russian prose.

| Avoid | Plain (глагол) |
|-------|-------------|
| «осуществление проверки документов» | «проверили документы» |
| «принятие решения о запуске» | «решили запустить» |
| «обеспечение возможности доступа» | «позволяет получить доступ» |
| «производит оценку ситуации» | «оценивает ситуацию» |
| «выполняет функцию защиты» | «защищает» |
| «реализация процесса оптимизации» | «внедрили/ускорили» |
| «осуществление мониторинга» | «мониторим» |
| «внедрение инструмента» | «внедрили инструмент» |

Chain of abstract nouns (nominalization + genitive): «процесс оптимизации системы мониторинга производительности» → «ускорили мониторинг» / «система стала быстрее».

Канцелярит connective phrases:

- «в рамках» («в рамках реализации проекта» → «в проекте»)
- «в целях» («в целях повышения эффективности» → «чтобы ускорить работу»)
- «в части» · «по направлению» · «на основании»
- «на текущий момент времени» → «сейчас» / «сегодня»
- «В связи с этим…» → cut or show the link concretely
- «рассматривается вопрос о…» → name the decision
- «принимаются меры» → name the measures, or cut

## Copula Crutches («является», «данный»)

- «Данный подход является эффективным» → «Этот подход эффективен» / «Подход эффективен».
- «Это является важным фактором» → «Это важно».
- «Продукт является решением проблемы» → «Продукт решает проблему».
- «Данные инструменты» → «Эти инструменты».
- «В рамках данного проекта» → «В этом проекте».
- «Указанные выше пункты» → «Эти пункты».
- «Вышеупомянутая задача» → «Эта задача».

«Является» is a linguistic crutch: when the model doesn't know which verb to choose, it attaches «является» plus a noun/adjective. A live verb nearly always wins. Exception: scientific and legal register.

## Adverbs, Intensifiers, Hedges (наречия-усилители)

Kill empty emphasis. No softeners, no intensifiers, no hedges doing nothing.

- «действительно»
- «на самом деле»
- «безусловно»
- «несомненно»
- «очевидно»
- «по сути»
- «в целом»
- «фактически»
- «в значительной степени»
- «в определённой степени»
- «существенно»
- «значительно»
- «кардинально» (already listed as superlative)
- «конечно»
- «конечно же»
- «естественно»
- «безусловно»
- «представляется, что…» (канцелярский хедж) → «скорее всего» / «похоже» / plain claim with source

Also cut:

- «На самом деле» as a trapdoor into every paragraph
- «В определённом смысле»
- «Как уже было сказано» (meta-commentary)
- «Нельзя не признать, что…»

## English Calques (ложные кальки с английского)

Russian LLMs translate English AI idioms literally; they land as translationese.

| Calque | Plain Russian |
|--------|---------------|
| «в конце дня» (at the end of the day) | «в итоге» |
| «на одной странице» (on the same page) | «одинаково понимаем» |
| «давайте нырнём» (let's dive in) | «разберёмся» |
| «это меняет игру» (game changer) | name what changes |
| «в сердце X» (at the heart of X) | «в основе X» |
| «думать за пределами коробки» (out of the box) | «нестандартно подойти» |
| «на следующем уровне» (next level) | «лучше в конкретном X» |
| «разблокировать потенциал» (unlock potential) | «использовать сильнее» |
| «двигатель роста» (growth engine) | «что растит бизнес» |
| «ландшафт рынка» (market landscape) | «как устроен рынок» |
| «играет ключевую роль» (plays a key role) | «важно для» / name the role |
| «в конце концов» used as filler | cut or «в итоге» |
| «под капотом» (under the hood) | «внутри» / «как это работает» |

In English these phrases are established and neutral. In Russian they sound like a bad translation — because they are one.

## Meta-Commentary (мета-комментарии)

Remove self-referential asides. The text should move, not announce its own structure.

- «Давайте разберёмся…»
- «Давайте посмотрим поближе…»
- «И вот здесь начинается самое интересное»
- «Теперь перейдём к…»
- «Следующий аспект…»
- «Рассмотрим подробнее…»
- «В данной статье мы рассмотрим…»
- «Как мы увидим далее…»
- «Погрузимся в…»
- «Хочу обратить ваше внимание на…»
- «Вот о чём пойдёт речь»

## Chatbot Artifacts (артефакты чатбота)

Phrases that reveal a conversational AI answering a prompt:

- «Надеюсь, это было полезно!»
- «Если у вас остались вопросы, обращайтесь»
- «Вот вариант:»
- «Вот что можно сделать:»
- «Надеюсь, помог»
- «Давайте уточним детали»
- «Подытожим вышесказанное»
- «Как уже упоминалось ранее»

## Performative Emphasis (ложная многозначительность)

Announcing significance instead of showing it:

- «Это не просто X — это Y»
- «Скорость решает всё»
- «Время — деньги» used as a filler proverb
- «Смысл в том, что…» without saying the meaning
- «Главное — начать»
- «Всё гениальное просто»

## Vague Declaratives (размытые обобщения)

Sentences that announce importance without naming the specific thing:

- «Реализация данного решения является ключевым фактором успеха»
- «Данные играют важную роль в процессе принятия решений»
- «Это оказывает положительное влияние на процессы»
- «Эксперты считают…» (размытый авторитет)
- «Многие компании сталкиваются с этой проблемой»
- «Результаты говорят сами за себя»

If a sentence says something is important/deep/structural without showing the specific thing, cut it or replace it with the specific thing.

## Lazy Absolutes (чрезмерные обобщения)

- «всегда» · «никогда» · «все» · «каждый» · «любой»
- «навсегда» · «полностью»
- «стопроцентно» · «гарантированно»

Used as sweeping claims instead of specifics. «Эта функция работает всегда» → state the condition.

## Sentence Level: формальные конструкции

- «Не только X, но и Y» — more than twice per text becomes a tell; vary connectives.
- «С одной стороны… с другой стороны…» used for false balance → take a position.
- «От X до Y» for unrelated concepts («от сингулярности до космической паутины») → enumerate or name one real range.
- «Существует мнение, что…» → attribute the opinion or drop it.
- «Следует отметить» already listed above — repeated use is the strongest signal.

## False Agency (неодушевлённый субъект)

Giving inanimate things human verbs. Russian AI loves this to avoid naming the actor.

| Pattern | Problem |
|---------|---------|
| «Событие подчёркивает…» | The event highlighted nothing. Someone drew a conclusion. |
| «Тренд отражает…» | Trends don't reflect. Someone read the data. |
| «Данные говорят нам…» | Data sits there. Someone reads it. |
| «Решение позволяет компании» | The decision does nothing. The company acts. |
| «Вывод напрашивается…» | The writer draws the conclusion. |
| «Опыт показывает…» | Experience is not a subject. Name the person/company. |

**Instead:** name the human. «Команда проверила данные и увидела…» beats «Данные говорят о…». If no specific person fits, use «вы»/«ты» to put the reader in the seat.

## Telling Instead of Showing (объявление вместо демонстрации)

- «Это по-настоящему сложно» → show the difficulty: «На настройку ушла неделя».
- «Вот как выглядит настоящий профессионализм» → show the act.
- «Это действительно важно» → name what it changes for the reader.
