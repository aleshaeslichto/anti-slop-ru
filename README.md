# anti-slop-ru

Скилл для Claude Code, opencode и других агентов: убирает предсказуемые машинные штампы («AI slop») из русской прозы.

Русский AI-текст имеет свой почерк, который не ловится механическим переводом английских humanizer-правил. Скилл целится в русские маркеры:

- **канцелярит и номинализация:** «осуществление проверки документов» вместо «проверили документы»;
- **цепочки родительного падежа:** «процесс оптимизации системы мониторинга производительности»;
- **слова-костыли:** «является», «данный», «указанный»;
- **шаблонные конструкции:** «не просто X, а Y», абстрактные триады, формульные выводы;
- **пустые превосходные степени** и маркетинговые клише: «революционный», «раскрыть потенциал»;
- **кальки с английского:** «в конце дня», «давайте нырнём», «это меняет игру»;
- **перегруз тире** и зеркальные конструкции;
- **придуманная конкретика:** скилл не добавляет факты, цифры, примеры и обещания, которых не было в исходнике.

Скилл сохраняет смысл, числа, имена, причинно-следственные связи, регистр и голос автора. Он не «оживляет» текст за счёт вымысла: правки делаются удалением и перестройкой, а не дописыванием.

## Режимы работы

Скилл выбирает глубину правки по формулировке запроса:

| Режим | Как просят | Что делает |
|-------|------------|------------|
| **Полная правка** | «сделай текст живее», «перепиши по-человечески», «пахнет нейросетью», «причеши» | чистит шаблоны по всему тексту |
| **Бережная корректура** | «вычитай», «поправь ошибки», «мой стиль оставь» | исправляет язык, не переписывая |
| **Аудит без правки** | «что здесь выдаёт нейросеть?», «только отметь, не переписывай» | цитирует проблемные места и объясняет |
| **Точечная правка** | «убери повторы», «сократи вступление», «упрости официальные обороты» | меняет только названное |
| **Сохранение регистра** | «сделай живее, но официальный тон оставь» | улучшает читаемость, не уходя в разговорный стиль |

В научных, юридических и деловых текстах часть «маркеров» — норма регистра, и скилл их не трогает. Голос автора калибруется: «ты»/«Вы», тип тире, кавычки, «ё».

## Пример

**До:**

> В современном мире, где технологии не стоят на месте, AI-ассистенты являются неотъемлемой частью процесса разработки программного обеспечения. Стоит отметить, что данные инструменты позволяют существенно повысить эффективность работы инженеров, обеспечивая сокращение времени на рутинные задачи до 40%.

**После:**

> AI-ассистенты уже стали частью разработки ПО. Они помогают инженерам работать эффективнее и сокращают время на рутинные задачи до 40%.

## Структура

```
anti-slop-ru/
├── SKILL.md                  # основной скилл (инструкции агенту, английский)
├── references/
│   ├── phrases.md            # фразы-маркеры: подводки, канцелярит, кальки, превосходные степени
│   ├── structures.md         # структуры-маркеры: номинализация, цепочки, тире, пассив
│   ├── examples.md           # примеры «до/после» на русском
│   └── triggers.md           # естественные формулировки запросов и выбор режима
├── translations/ru/          # русский перевод материалов скилла — для чтения человеком
│   ├── SKILL.ru.md           #   ⚠️ скилл эти файлы не использует
│   ├── phrases.ru.md
│   ├── structures.ru.md
│   ├── examples.ru.md
│   └── triggers.ru.md
├── evals/
│   └── evals.json            # 4 тестовых сценария
├── LICENSE
└── README.md
```

## Подключение

**opencode.** Зарегистрируй папку через `skills.paths` в `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "skills": {
    "paths": ["~/gh-repos/anti-slop-ru"]
  }
}
```

Либо скопируй папку в `<проект>/.opencode/skills/anti-slop-ru/`. После — перезапусти opencode.

**Claude Code.** Скопируй папку в `~/.claude/skills/anti-slop-ru/`.

**Другие агенты.** Формат `SKILL.md` стандартный: положи папку в каталог скиллов агента.

## Использование

Напиши агенту запрос обычными словами, например:

- «Сделай текст живее и понятнее»;
- «Перепиши по-человечески, а то звучит как ChatGPT»;
- «Причеши этот абзац, смысл и цифры оставь»;
- «Что здесь выдаёт нейросеть? Только отметь, не переписывай»;
- «Сделай живее, но официальный тон оставь».

Скилл сам выберет режим и глубину правки. Пул формулировок и правила маршрутизации — в `references/triggers.md`.

## Тесты

`evals/evals.json` содержит четыре сценария: полная правка, правка с сохранением делового регистра, аудит без переписывания и точечная правка повторов.

## О языках

Основной скилл (`SKILL.md` и `references/`) написан на английском — это язык инструкций для модели; русские фразы-маркеры включены в него как объекты работы. Русский перевод в `translations/ru/` сделан для чтения человеком и скиллом не используется.
