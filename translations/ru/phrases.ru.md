# Фразы, которые нужно убирать (русский перевод `references/phrases.md`)

> ⚠️ **Технический документ.** Не часть скилла. Перевод `references/phrases.md` на русский для чтения человеком.

Русские примеры показывают повторяющиеся редакторские проблемы: канцелярит, шаблонные подводки, раздутые утверждения, кальки и чатботную подачу. Считай их контекстными признаками, а не списком слов, которые нужно механически запрещать.

## Пустые подводки (Throat-Clearing Openers)

Убирай эти фразы-объявления. Говори содержание напрямую.

- «Стоит отметить, что…»
- «Важно отметить, что…»
- «Важно понимать, что…»
- «Важно помнить, что…»
- «Следует отметить, что…»
- «Следует подчеркнуть, что…»
- «Нельзя не отметить…»
- «Необходимо отметить, что…»
- «Можно с уверенностью сказать, что…»
- «Хочется отметить, что…»
- «Стоит подчеркнуть, что…»

Любая подводка «отметить/подчеркнуть/сказать» — это объявление пункта вместо самого пункта. Убери подводку и оставь утверждение. Становится короче и бьёт точнее:

- «Стоит отметить, что сроки сократились» → «Сроки сократились».
- «Важно понимать, что данные уже в контуре» → «Данные уже в контуре».

## Штампы «современной эпохи» (Era Clichés)

Самый узнаваемый русский AI-маркер — открывающая фраза про время вместо сути.

- «В современном мире…»
- «В современном мире, где технологии не стоят на месте…»
- «В эпоху цифровизации…»
- «В эпоху стремительного развития технологий…»
- «В условиях быстро меняющегося мира…»
- «В условиях высокой конкуренции…»
- «В условиях неопределённости…»
- «Технологии не стоят на месте»
- «Мир не стоит на месте»
- «Сегодня, как никогда…»

Эти открывашки — сигнал, что следующие несколько сотен слов можно не читать. Начинай с факта, цифры или конкретной ситуации.

- «В современном мире данные становятся ключевым активом» → «Данные уже определяют сроки сдачи отчётов — вот пример с объекта N».

## Пустые превосходные степени (Empty Superlatives)

Модели любят масштаб. Каждое слово — маркер, если рядом нет факта, который его подтверждает.

- «революционный»
- «уникальный»
- «беспрецедентный»
- «непревзойдённый»
- «первоклассный»
- «инновационный»
- «прорывной»
- «передовой»
- «кардинально»
- «потрясающий»
- «новый уровень» / «новая эра» / «новая реальность»
- «неотъемлемая часть»
- «ключевой элемент»
- «максимально эффективный»
- «критически важный» / «стратегически важный»

Заменяй фактом («снизили ошибки на 40%») или убирай прилагательное. «Революционный подход к управлению» без объяснения, чем он революционный, — пустышка; «срок с 14 дней до 3» не нуждается в эпитетах.

## Маркетинговые клише (Business Jargon)

Заменяй на простой язык.

| Не надо | Вместо |
|-------|-------------|
| «Раскрыть потенциал» / «разблокировать потенциал» | «Использовать сильнее» / «получить X» |
| «Комплексный подход» / «комплексное решение» | Перечисли, что туда реально входит |
| «Открывает новые горизонты/перспективы/возможности» | Назови конкретную новую возможность |
| «Синергия» / «win-win» | «Совмещает X и Y» / «выгода для обеих сторон: …» |
| «Драйвер роста» / «двигатель роста» | «Что растит выручку» / «что ускоряет внедрение» |
| «Экосистема решений» / «ландшафт» / «парадигма» | «Набор модулей» / «рынок инструментов» / «подход» |
| «Лучшие практики» | Назови саму практику |
| «Exit-стратегия», «actionable insights», «value add» | Русский эквивалент или устоявшийся термин |

## Канцелярит — главный русский AI-маркер

Модели превращают глаголы в отглагольные существительные и раздувают фразу. Это самый сильный признак машинного текста в русском.

| Не надо | Просто (глагол) |
|-------|-------------|
| «осуществление проверки документов» | «проверили документы» |
| «принятие решения о запуске» | «решили запустить» |
| «обеспечение возможности доступа» | «позволяет получить доступ» |
| «производит оценку ситуации» | «оценивает ситуацию» |
| «выполняет функцию защиты» | «защищает» |
| «реализация процесса оптимизации» | «внедрили/ускорили» |
| «осуществление мониторинга» | «мониторим» |
| «внедрение инструмента» | «внедрили инструмент» |

Цепочка отглагольных существительных (номинализация + родительный): «процесс оптимизации системы мониторинга производительности» → «ускорили мониторинг» / «система стала быстрее».

Канцелярские слова-связки:

- «в рамках» («в рамках реализации проекта» → «в проекте»)
- «в целях» («в целях повышения эффективности» → «чтобы ускорить работу»)
- «в части» · «по направлению» · «на основании»
- «на текущий момент времени» → «сейчас» / «сегодня»
- «В связи с этим…» → убери или покажи связь конкретно
- «рассматривается вопрос о…» → назови решение
- «принимаются меры» → назови меры или убери

## Слова-костыли «является», «данный» (Copula Crutches)

- «Данный подход является эффективным» → «Этот подход эффективен» / «Подход эффективен».
- «Это является важным фактором» → «Это важно».
- «Продукт является решением проблемы» → «Продукт решает проблему».
- «Данные инструменты» → «Эти инструменты».
- «В рамках данного проекта» → «В этом проекте».
- «Указанные выше пункты» → «Эти пункты».
- «Вышеупомянутая задача» → «Эта задача».

«Является» — лингвистический костыль: когда модель не знает, какой глагол выбрать, она ставит «является» плюс существительное/прилагательное. Живой глагол почти всегда выигрывает. Исключение: научный и юридический регистр.

## Наречия-усилители, хеджи (Adverbs, Intensifiers, Hedges)

Убирай пустое усиление. Никаких смягчителей, усилителей и хеджей, которые ничего не делают.

- «действительно»
- «на самом деле»
- «безусловно»
- «несомненно»
- «очевидно»
- «по сути»
- «в целом»
- «фактически»
- «в значительной степени»
- «в определённой степени»
- «существенно»
- «значительно»
- «кардинально» (уже в превосходных)
- «конечно»
- «конечно же»
- «естественно»
- «представляется, что…» (канцелярский хедж) → «скорее всего» / «похоже» / прямое утверждение с источником

Также убирай:

- «На самом деле» как трамплин в каждый абзац
- «В определённом смысле»
- «Как уже было сказано» (мета-комментарий)
- «Нельзя не признать, что…»

## Ложные кальки с английского (English Calques)

Русские LLM переводят английские AI-идиомы буквально; получается переводческая.

| Калька | Обычный русский |
|--------|---------------|
| «в конце дня» (at the end of the day) | «в итоге» |
| «на одной странице» (on the same page) | «одинаково понимаем» |
| «давайте нырнём» (let's dive in) | «разберёмся» |
| «это меняет игру» (game changer) | назови, что именно меняется |
| «в сердце X» (at the heart of X) | «в основе X» |
| «думать за пределами коробки» (out of the box) | «нестандартно подойти» |
| «на следующем уровне» (next level) | «лучше в конкретном X» |
| «разблокировать потенциал» (unlock potential) | «использовать сильнее» |
| «двигатель роста» (growth engine) | «что растит бизнес» |
| «ландшафт рынка» (market landscape) | «как устроен рынок» |
| «играет ключевую роль» (plays a key role) | «важно для» / назови роль |
| «в конце концов» как мусорная связка | убери или «в итоге» |
| «под капотом» (under the hood) | «внутри» / «как это работает» |

В английском эти фразы устоявшиеся и нейтральные. В русском они звучат как неумелый перевод — потому что это он и есть.

## Мета-комментарии (Meta-Commentary)

Убирай самоссылочные отступления. Текст должен двигаться, а не объявлять свою структуру.

- «Давайте разберёмся…»
- «Давайте посмотрим поближе…»
- «И вот здесь начинается самое интересное»
- «Теперь перейдём к…»
- «Следующий аспект…»
- «Рассмотрим подробнее…»
- «В данной статье мы рассмотрим…»
- «Как мы увидим далее…»
- «Погрузимся в…»
- «Хочу обратить ваше внимание на…»
- «Вот о чём пойдёт речь»

## Артефакты чатбота (Chatbot Artifacts)

Фразы, выдающие диалоговый ИИ, отвечающий на промпт:

- «Надеюсь, это было полезно!»
- «Если у вас остались вопросы, обращайтесь»
- «Вот вариант:»
- «Вот что можно сделать:»
- «Надеюсь, помог»
- «Давайте уточним детали»
- «Подытожим вышесказанное»
- «Как уже упоминалось ранее»

## Ложная многозначительность (Performative Emphasis)

Объявление значимости вместо её демонстрации:

- «Это не просто X — это Y»
- «Скорость решает всё»
- «Время — деньги» как фраза-наполнитель
- «Смысл в том, что…» без называния смысла
- «Главное — начать»
- «Всё гениальное просто»

## Размытые обобщения (Vague Declaratives)

Предложения, которые объявляют важность, не называя конкретную вещь:

- «Реализация данного решения является ключевым фактором успеха»
- «Данные играют важную роль в процессе принятия решений»
- «Это оказывает положительное влияние на процессы»
- «Эксперты считают…» (размытый авторитет)
- «Многие компании сталкиваются с этой проблемой»
- «Результаты говорят сами за себя»

Если предложение говорит, что что-то важно/глубоко/структурно, не показывая конкретную вещь, вырежи его или замени на конкретную вещь.

## Ленивые обобщения (Lazy Absolutes)

- «всегда» · «никогда» · «все» · «каждый» · «любой»
- «навсегда» · «полностью»
- «стопроцентно» · «гарантированно»

Используются как размашистые утверждения вместо конкретики. «Эта функция работает всегда» → укажи условие.

## Формальные конструкции (Sentence Level)

- «Не только X, но и Y» — чаще двух раз на текст становится маркером; разнообразь связки.
- «С одной стороны… с другой стороны…» для ложного баланса → займи позицию.
- «От X до Y» для несвязанных понятий («от сингулярности до космической паутины») → перечисли или назови один реальный диапазон.
- «Существует мнение, что…» → припиши мнение конкретному человеку или убери.
- «Следует отметить» уже в списке выше — повторение самый сильный сигнал.

## Неодушевлённый субъект (False Agency)

Наделение неживых предметов человеческими глаголами. Русский AI любит это, чтобы не называть деятеля.

| Паттерн | Проблема |
|---------|---------|
| «Событие подчёркивает…» | Событие ничего не подчёркивало. Вывод сделал человек. |
| «Тренд отражает…» | Тренды не отражают. Кто-то прочитал данные. |
| «Данные говорят нам…» | Данные лежат. Кто-то их читает. |
| «Решение позволяет компании» | Решение ничего не делает. Компания действует. |
| «Вывод напрашивается…» | Вывод делает автор. |
| «Опыт показывает…» | Опыт не субъект. Назови человека/компанию. |

**Вместо этого:** назови человека. «Команда проверила данные и увидела…» лучше, чем «Данные говорят о…». Если конкретного человека нет, используй «вы»/«ты», чтобы посадить читателя в кресло.

## Объявление вместо демонстрации (Telling Instead of Showing)

- «Это по-настоящему сложно» → покажи сложность: «На настройку ушла неделя».
- «Вот как выглядит настоящий профессионализм» → покажи поступок.
- «Это действительно важно» → назови, что это меняет для читателя.
